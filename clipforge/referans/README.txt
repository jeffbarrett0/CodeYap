REFERANS KLASÖRÜ
================
Beğendiğin videoları ve fotoğrafları (ekran görüntüleri dahil) BU klasöre koy.
Claude Code buradan okur: videolar için kare tablosu + ölçüm çıkarır, fotoğraflara bakar,
tarzını inceler ve ClipForge'a uyarlar.

Claude Code'a şunu yazman yeterli:  "referans klasörünü incele ve uyarla"

ÖNEMLİ — dosyalar bana nasıl ulaşır?
  Claude Code bulut ortamında çalışıyorsa senin bilgisayarındaki dosyaları GÖREMEZ.
  Koyduktan sonra GitHub'a gönder:
      git add referans
      git commit -m "referans eklendi"
      git push
  (GitHub tek dosyada 100 MB sınırı koyar; daha büyük videoyu sohbete ek olarak at.)
  Claude Code kendi bilgisayarında çalışıyorsa göndermene gerek yok.

Kurallar: başka kanalların adı/logosu kopyalanmaz; neyi beğendiğini kısa bir not.txt ile
yazarsan (ör. "alt yazı stili", "geçişler") daha isabetli uyarlarım.
